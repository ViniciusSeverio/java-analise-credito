# 💳 Java — Análise de Crédito

Exercício desenvolvido durante meus estudos de **Java**, com foco em estruturas condicionais e combinação de critérios para tomada de decisão.

## 🎯 Objetivo

Criar um programa capaz de analisar uma solicitação de crédito com base em dois critérios:

* Salário bruto
* Score de crédito

A partir desses dados, o programa determina se o crédito será aprovado ou informa o motivo da recusa.

## 📚 Conceitos praticados

* `Scanner`
* `double`
* `int`
* `if`
* `else if`
* `else`
* Operadores relacionais
* Operador lógico `&&`
* Combinação de condições
* Regras de negócio

## 🔎 Regras utilizadas

O crédito é aprovado quando:

```text
Salário >= 3000
E
Score >= 700
```

Caso contrário, o programa identifica se a recusa ocorreu por:

* Score insuficiente
* Renda insuficiente
* Renda e score insuficientes

## 💻 Exemplo

```text
Digite o salario bruto do cliente:
3500

Digite o score:
750

Crédito Aprovado.
```
